# Портфолио

Статический сайт на [Astro](https://astro.build), layout в духе шаблона Tabfolio.

## Запуск

```bash
npm install     # один раз
npm run dev     # локально: http://localhost:4321
npm run build   # готовый сайт в папке dist/
```

## Языки

Основная версия — английская (`/`, `/about/`…), дополнительная — русская (`/ru/`, `/ru/about/`…).
Переключатель EN / RU в шапке ведёт на ту же страницу на другом языке.

- **Контент** — в `src/data/site.ts` и в файлах кейсов каждый текст записан парой `en` / `ru`.
  Если забыть один из языков, сборка подсветит ошибку.
- **Подписи интерфейса** (меню, кнопки, заголовки секций) — `src/i18n/ui.ts`.
- **Список языков** — `src/i18n/config.ts`.
- **Страницы** лежат в `src/pages/[...locale]/` — один файл собирается сразу в обе версии.

## Где что менять

- **Тексты сайта** — `src/data/site.ts`: имя, фраза в шапке, почта, соцсети, «How I think», «Обо мне», резюме.
- **Кейсы** — по файлу на кейс в `src/content/cases/` (`имя-кейса.yaml`, имя файла = адрес `/projects/имя-кейса/`).
  - Порядок на главной — поле `order`. `featured: true` — крупная карточка вверху главной,
    остальные идут сеткой в две колонки. `archived: true` убирает кейс на страницу `/archive/`.
    `draft: true` — кейс нигде не публикуется (страница не собирается).
  - `types` — теги и фильтры на главной: `systems`, `ai`, `experience`.
  - Разделы страницы: `problem`, `constraints`, `myRole`, `decisions`, `cut`, `artifact`, `outcome`, `learned`, `next`.
    Нет раздела в файле — его нет на странице. Описание всех полей — `src/content.config.ts`.
  - Иллюстрации — список `visuals` в YAML кейса: тип (`flow`, `chain`, `chat`, `scale`, `matrix`,
    `rejected`, `stats`, `rule-task`, `item-analysis`), раздел страницы и тексты en / ru.
    Компоненты — `src/components/visuals/`.
  - Обложка карточки — `coverFragment` в YAML кейса: фрагмент выдуманного интерфейса
    (`task-card`, `chat`, `picker`, `catalog-card`, `review-row`). Цвет — по первому типу из `types`
    или по `coverType`. Компонент — `src/components/case/CaseCover.astro`.
  - Все примеры в иллюстрациях выдуманные и из другой области: никаких реальных артефактов работодателя.
  - Данные графика item analysis — условные, `node scripts/generate-item-analysis.mjs`.
- **TODO** — недописанные места. В локальной версии (`npm run dev`) текст с `TODO` подсвечен жёлтым.
  **Сборка падает, если на страницах остался TODO** — так недописанное не попадёт на сайт.
  Черновая сборка, чтобы просто посмотреть: `ALLOW_TODO=1 npm run build` (только предупреждение).
- **Обложки не обрезаются** — `npm run check:covers` при запущенном `npm run dev`: открывает главную и кейсы
  в Chrome на 1440, 1280, 768 и 375px и падает, если текст фрагмента на обложке обрезан
  (и в обычном виде, и после анимации). Другой адрес: `npm run check:covers -- http://localhost:4322`.
  Недописанный кейс можно спрятать: `draft: true`.
- **Фото и картинки** — кладите в `public/` и указывайте путь:
  - аватар: `avatar: '/avatar.jpg'` в `site.ts`
  - обложка кейса: `cover: '/projects/имя.jpg'` в YAML кейса (лучше 16:9, ~1600px по ширине)
- **Цвета, шрифт, отступы** — переменные в начале `src/styles/global.css`.
- **Страницы** — `src/pages/` (каждый файл = адрес на сайте).

## Деплой

Сайт собирается в обычные HTML-файлы (`dist/`), поэтому подходит любой хостинг статики.
Команда сборки: `npm run build`, папка с результатом: `dist`.

Сейчас сайт живёт на VPS у Webdock (Дания): nginx отдаёт `/var/www/portfolio`, HTTPS — Let's Encrypt
(certbot продлевает сам). Каждый push в `main` собирает сайт в GitHub Actions и копирует `dist/`
на сервер через rsync (`.github/workflows/deploy.yml`). Ключ из секрета `DEPLOY_SSH_KEY` на сервере
разрешает только rsync в папку сайта, `DEPLOY_KNOWN_HOSTS` — проверенный ключ сервера.
