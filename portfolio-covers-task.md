# Задача: новые обложки карточек кейсов — фрагменты интерфейса

Дополнение к `portfolio-illustrations-plan.md`. **Заменяет раздел 5 «Обложки карточек»** из того плана: обложки больше не миниатюры схем, а крупные фрагменты воссозданного интерфейса. Схемы остаются внутри кейсов.

Правила интеллектуальной собственности из раздела 1 плана иллюстраций действуют полностью: весь текст на обложках выдуманный, из небанковских предметных областей, без реальных вопросов, заданий, данных, названий и фирменного стиля работодателя.

---

## 1. Почему меняем

Текущие обложки (пустые блоки на сером поле) читаются как заглушки загрузки: в них нет содержания, схема занимает малую часть карточки, контраст низкий. Новая обложка должна за секунду показывать, *что почувствует пользователь этого решения*.

---

## 2. Принципы обложки

1. **Один фрагмент интерфейса крупным планом**, а не целый экран. Фрагмент занимает 60–80% площади обложки.
2. **В фрагменте есть момент решения**: выбор, вопрос, развилка. Не статичный текст.
3. **Реальные (синтетические) слова**, читаемые без увеличения: минимум 13px на десктопе.
4. **Нейтральный UI**, не похожий на конкретный продукт: без логотипов, аватаров реальных людей, узнаваемых паттернов конкретных платформ.
5. **Цвет фона карточки — по основному типу работы** (п. 3).
6. **Без подписей «Recreated for illustration» на обложках** — подпись остаётся только у визуалов внутри кейса.

|---|---|---|---|

Тёмная тема: фон — тёмная ступень того же оттенка, фрагменты интерфейса — на поверхности сайта, акценты светлее. Проверь контраст текста (WCAG AA).

## 4. Компонент `CaseCover`

- Перепиши текущий режим `thumbnail` или сделай новый компонент `CoverFragment`, а старый удали, если он больше нигде не используется.
- Пропсы: `type` (определяет цвет), `variant` (один из шаблонов ниже), `content` (тексты из frontmatter или i18n).
- Шаблоны фрагментов (переиспользуемые):
  - `task-card` — карточка задания: метка, текст ситуации, 2 кнопки-варианта, одна выделена.
  - `chat` — 2–3 пузыря диалога, бот слева, пользователь справа акцентом.
  - `picker` — мини-инструмент: 2 параметра с выбранными значениями → результат.
  - `catalog-card` — карточка курса с персонализированной подписью.
  - `review-row` — строка аналитики: вопрос теста + метрики + флажок проблемы.
- Тексты фрагментов — в i18n (EN/RU), не захардкожены.
- Пропорции обложки — как у текущих карточек. На мобильных фрагмент масштабируется, не обрезается по тексту.

### Анимация

- При наведении на карточку (десктоп): короткое действие внутри фрагмента — выделенная кнопка «нажимается», следующий пузырь чата появляется, выбранное значение в picker переключается. Длительность 300–600 мс, без зацикливания.
- На мобильных: то же действие один раз при появлении карточки в зоне видимости (IntersectionObserver).
- Уважать `prefers-reduced-motion`: без анимации, сразу конечное состояние.
- Без тяжёлых библиотек: CSS-транзиции + минимальный JS.

## 7. Критерии готовности

- На каждой обложке читаемый текст и момент решения.
- Фрагмент занимает большую часть обложки.
- Цвет карточки соответствует типу работы, сетка на главной не монотонная.
- Анимация короткая, не зацикленная, отключается при `prefers-reduced-motion`.
- Ни одна обложка не содержит реального контента или стиля работодателя.
- EN и RU совпадают; на 375px нет обрезанного текста и горизонтального скролла.
